# Chula Student Assistant

## Project Overview
Chula Student Assistant is a locally running AI chatbot designed to help Chulalongkorn University students find information about university life, academic regulations, course registration, and student services.

The project uses a local Large Language Model (LLM) with university-specific documents to provide relevant answers to students' questions.

## Objectives
- Make university information easier for students to access.
- Provide answers based on official Chulalongkorn University documents.
- Explore how local knowledge can improve the accuracy and relevance of generative AI.

## Knowledge Sources
The chatbot uses university-related materials, including:
- Chulalongkorn University Student Handbook
- Course Registration Manual
- Undergraduate Studies Regulations
- Academic Calendar
- Student Discipline Regulations

## Technologies
- Python
- Ollama
- Gemma 3:1B
- Flask

## How It Works
The application processes university documents and uses their contents as additional knowledge when answering user questions.

## Project Status
Currently under development as part of a Generative AI Application course assignment.
